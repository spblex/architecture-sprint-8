### Запуск проекта

Для запуска проекта выполните команду:

```docker-compose up --build```

### Тест: получение отчета пользователем с ролью prothetic_user

1. Откройте браузер в приватном режиме
2. Перейдите по адресу: http://localhost:3000
3. на странице логина введите:
   
    login: prothetic1
    password: prothetic123
   
4. Откроется страница для скачивания отчетов.
5. Нажмите на кнопку скачать отчет
6. В окне отобразится отчет с сервера 
7. Тест завершен успешно

### Тест: отказ в получении отчета пользователем без роли prothetic_user

1. Откройте браузер в приватном режиме
2. Перейдите по адресу: http://localhost:3000
3. на странице логина введите:

   login: user1
   password: password123

4. Откроется страница для скачивания отчетов.
5. Нажмите на кнопку скачать отчет
6. В окне отобразится ошибка: Server error [403]: Forbidden
7. Тест завершен успешно
